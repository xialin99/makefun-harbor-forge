# Harbor Forge

An in-memory Git forge with Git smart HTTP, REST, GraphQL and MCP interfaces.

## Run

Node.js 22.18 or newer. Set MAKEFUN_ENV_URL and MAKEFUN_SHOP_TOKEN for the supplied test harness, then run node main.ts.
